# Contributing

Edit `src/index.template.html`, not generated files under `dist/`.

Use Node.js 22 or later and PowerShell 7 (or Windows PowerShell 5.1). Before opening a pull request on Windows:

```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-repository.ps1
```

Keep the application dependency-free unless a new dependency materially reduces implementation risk.

The repository check builds both variants, refreshes `signal-screen.html`, runs the current behavior regression suite against source/readable/self-extract/root variants, and verifies byte/application parity. The dependency-free Node harness uses DOM and geometry doubles; run browser QA for actual layout, Tab order, native dialogs, fullscreen fallback, QR visibility, keyboard-safe mobile actions, and saved-signal operations at 320px and wider mobile widths. Keep the README screenshots aligned with released builds; release screenshots are generated by `scripts/release-screenshots.browser.cjs`. Never enable flashing during automated or routine browser QA.
