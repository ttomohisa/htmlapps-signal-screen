# Offline verification

1. Build the repository.
2. Open `dist/index.html` directly.
3. Enter a message, change colors, open the stage, close it, and reload to verify persistence.
4. Confirm no network request occurs.
5. Open `dist/index.self-extract.html`; confirm loader text is readable and the favicon matches.
6. Confirm the restored app behaves the same as the readable version.
